Physical Layer

The components that bring the smart home to life.

These hardware modules work together with the server to control devices, collect data, and execute automation commands in the home.

Hardware + software integration
Controller

ESP32 / ESP8266

Acts as the IoT node that connects sensors and appliances to the smart home network.

  • Handles Wi-Fi connectivity
  • Talks to the server or relay hardware
  • Enables scalable smart device expansion
Server

Node.js Server

Receives user commands and synchronizes device state across the interface.

  • Exposes control endpoints
  • Processes toggle requests
  • Returns real-time feedback
Switching

Relay Module

Converts digital commands into real switching behavior for lights and appliances.

  • Safe appliance control
  • Supports on/off switching
  • Useful for automation routines
Awareness

Sensors

Sensors can help the home make smart decisions instead of only manual responses.

  • Motion detection
  • Temperature and environment monitoring
  • Automation trigger events
